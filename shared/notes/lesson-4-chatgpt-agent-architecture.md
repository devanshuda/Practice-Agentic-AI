# Lesson 4 - Agent Architecture

## AI Workflow vs AI Agent

### Workflow

Predefined sequence of steps.

### Agent

Can reason, decide and act dynamically.

## Agent Loop

Observe
↓
Reason
↓
Act
↓
Observe

## Agent Components

### LLM

Reasoning engine.

### Tools

Perform actions.

### Memory

Stores previous information.

### RAG

Provides external knowledge.

## Key Takeaways

Agents combine reasoning with actions.
