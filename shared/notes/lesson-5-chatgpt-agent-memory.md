# Lesson 5 - Agent Memory

## What is Memory?

Information retained across interactions.

## Types

### Short-Term Memory

Current conversation.

### Long-Term Memory

Persistent information.

Examples:

* Previous reports
* User preferences
* Exceptions

## Enterprise Examples

Terraform Drift Agent:

* Previous drift reports
* Approved exceptions
* Resource ownership

## Memory vs RAG

Memory:

* Dynamic
* Session-specific

RAG:

* Stable knowledge
* Documentation

## Key Takeaways

Memory stores experience.
RAG stores knowledge.
