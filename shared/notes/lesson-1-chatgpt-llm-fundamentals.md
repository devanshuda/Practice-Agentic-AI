# Lesson 1 - LLM Fundamentals

## What is an LLM?

A Large Language Model (LLM) is a machine learning model trained on massive amounts of text data to understand and generate human language.

Examples:

* GPT
* Claude
* Gemini
* Llama
* Qwen

## Key Characteristics

* Predicts the next token in a sequence.
* Learns language patterns from training data.
* Does not inherently understand facts.
* Generates responses based on probabilities.

## Core Components

### Model

The neural network responsible for language understanding and generation.

### Prompt

Instructions provided to the model.

### Response

Generated output from the model.

## Key Takeaways

* LLMs are reasoning engines, not databases.
* LLMs can generate text but cannot perform actions without tools.
* LLMs form the foundation of modern AI agents.
